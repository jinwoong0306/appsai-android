# 진행 상태와 작업 목록

기준: 2026-11-02. 작업명은 앱사이(AppSai)이며 상표 검토는 미완료다. 발표 일정은 공지 기준이며 후속 공지를 확인해야 한다.

## 확인됨

- 기존 기술 검증용 MVP를 이 폴더로 복사했다. 이전 원본은 그대로 유지한다.
- 이전 에뮬레이터에서 실행 앱 목록, 친구 생성, 사용량 권한 거부·허용, 수동 조회, 예시 답장, 재시작 후 대화·경험치 유지, 중복 친구 방지를 확인했다.
- 현재 대화는 고정된 예시 답장이다. 선택한 성격에 따른 AI 반응이 아니다.
- 공통 화면 틀은 `activity_main.xml`로 전환했다. 화면별 항목은 아직 Java로 동적 생성되어 XML 기반 화면과 어댑터로 단계적 전환이 필요하다.
- 이 프로젝트에서 디버그 빌드에 성공하고 기존 에뮬레이터에 설치·실행했다. 홈 화면과 기존 친구 목록 표시를 확인했다. XML 전환 이후 전체 채팅·권한 흐름은 아직 회귀 검증하지 않았다.

## 중간 발표 전 우선

- [ ] 실제 구현 화면 캡처 및 시연 준비. 목업과 구현 화면을 구분한다.
- [ ] 홈·앱 선택·채팅·권한 안내의 전체 화면 흐름과 필수 기능 설계.
- [ ] 사용량 수동 조회, 로컬 저장, 제한사항을 실제 화면에서 설명한다.
- [ ] 팀원별 실제 개발 역할·진척과 남은 태스크를 확인해 발표에 반영한다.
- [ ] e-class에서 중간발표 제출 및 일정 변경 여부 확인.
