# v0.5.0-ui — 장착 위치와 세로 선택 목록

## 장착 위치 조정

- 최신 128px 캐릭터 9종에 맞춰 머리·눈·목·등·손 부착 기준을 분리했다.
- 눈 간격과 기울기에 맞춰 안경을 배치하며, 수염·반창고는 별도 기준점을 쓴다.
- 목 장식 높이, 등 소품 크기, 우산 손잡이 위치와 크기를 보정했다.
- 공통 여백 안에 몸체와 소품을 함께 배치해 소품 교체 때 몸체가 이동하지 않는다.
  원본 PNG는 변경하지 않았으며 최근접 보간을 유지한다.

## 세로 선택 목록

- 기존 친구 꾸미기와 새 친구 생성 모두 액세서리를 여러 행으로 배치한다.
- 일반 화면은 3열, 좁은 화면·큰 글꼴은 2열이며 극단적인 폭에서는 1열로 조정한다.
- 기존 세로 ScrollView 하나만 사용한다. 대표 미리보기와 저장/생성 동작은 고정한다.
- 같은 부위에서 소품을 고를 때 카드를 다시 만들지 않아 스크롤 위치가 유지된다.
- 보유품 제한·상점 연결·저장·취소·기존 외형 ID를 유지한다.

## 검사

본체·계측·설치 APK 빌드 성공. 최종 관련 계측 `OK (8 tests)`:

- 9종 × 30종의 변환된 소품 윤곽이 표시 영역 안에 있는지 검사.
- 눈 부착점 검사와 Android 렌더링 시트 9장 확인.
- 3/2열 대응, 긴 잠금 표시 줄바꿈, 세로 스크롤, 선택 후 위치 유지.
- 미리보기/동작 버튼 고정, 꾸미기 저장·취소, 상점 구매 회귀.

렌더링 자료: `app/build/character-alignment-final/`.
설치 APK: `app/build/outputs/deliverables/Appsai-v0.5.0-ui-debug.apk`.
Java LSP는 설치되지 않아 컴파일·계측·실제 렌더링으로 확인했다.

Galaxy S22 Ultra에 데이터 보존 업데이트 설치 후 홈과 꾸미기를 확인했다.
3열의 여러 액세서리 행을 아래로 스크롤하고 베레모를 선택했을 때
미리보기만 갱신되고 스크롤 위치와 고정 영역이 유지되는 것을 확인했다.
실제 화면 증거는 `app/build/ui-visible.png`, `ui-wardrobe.png`,
`ui-grid.png`, `ui-grid-selected.png`다.
확인용 베레모 선택은 취소해 기존 짚모자 선택으로 복원했고 저장 버튼의 비활성 상태를
확인했다. 임시 USB 화면 유지 설정도 원래 값으로 복원했다.
