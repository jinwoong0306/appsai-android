# v0.3.1-images — 최신 이미지 적용본

- 최신 스타일의 128px 캐릭터 9종을 앱의 공통 캐릭터 뷰에 적용했다.
- 기존 분리 몸체·표정·손을 합쳐진 새 이미지로 교체했다.
  기존 소품은 같은 표시 영역에 겹치며, 위치 맞춤은 검증하지 않았다.
- `./gradlew.bat :app:exportLatestImageApk --offline` 빌드 성공.
- 산출물: `app/build/outputs/deliverables/Appsai-latest-images-v0.3.1-debug.apk`.
  APK는 빌드 산출물이므로 Git에 포함하지 않는다.
- APK 내부 최신 캐릭터 PNG 9개, 기존 base 레이어 0개를 확인했다.
- 설치·화면·회귀 테스트는 실행하지 않은 빠른 이미지 적용본이다.
  v0.3.0의 테스트 통과 결과를 이 변경의 검증 결과로 간주하지 않는다.
