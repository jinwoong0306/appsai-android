# v0.2.0 — 친구 꾸미기와 설정

## 구현

- 우상단 설정에서 새 앱 친구 추가와 사용 정보 접근 설정을 실행한다.
- 하단 꾸미기에서 기존 친구를 선택하고 기본 캐릭터와 30종 소품을 변경한다.
- 머리 10, 얼굴 6, 목/몸 6, 등 4, 손소품 4개를 부위별로 장착·해제한다.
- 고정 미리보기, 변경 취소, 저장 및 저장하지 않은 변경의 이동 확인을 지원한다.
- DB 버전 4는 appearance에 body/back만 추가하며 기존 대화·경험치를 보존한다.

## 별도 검증

다른 API·실제 휴대폰·다크 모드·가로·큰 글꼴·TalkBack 전체 검증은 별도다.
기존 usage permission lint 오류는 해결된 것으로 표시하지 않는다.
이번 태그는 기능 작업 버전이며 상세 검증 완료 표시는 아니다.

## 포함된 기반 코드와 구성

이 버전은 앞서 로컬에 구현된 네이티브 UI·내비게이션·캐릭터 표시 기반도 함께 담는다.
병렬로 작성된 AI 동의·비동기 요청 코드는 현재 앱의 의존 코드라 보존한다.
실제 Gemini 모델 호출은 이 버전의 검증 근거가 아니며,
`google-services.json` 없이도 빌드되고 AI 미설정 상태를 표시한다.
해당 로컬 구성, 비밀 값, APK, 개인 캡처는 업로드하지 않는다.

현재 앱은 의상 장착 좌표가 호환되는 64px 분리 레이어를 사용한다.
별도 제작 중인 128/512px 합성 이미지의 장착 호환은 이 버전 범위가 아니다.
